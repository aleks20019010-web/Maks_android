# Макс Музыка — музыкальный ассистент для Android

Нативное **local-first** Android-приложение (**Kotlin + Jetpack Compose + Media3 ExoPlayer + Vosk + TTS**) с локальным музыкальным ядром Макса и опциональной интеграцией **Яндекс Музыки**.

* **Оффлайн-ядро и голос**: распознавание речи (`Vosk`), NLU, память привычек и озвучка работают локально на устройстве — без облачного ASR/TTS.
* **Локальная музыка в приоритете**: сканирует аудиофайлы с устройства (`MP3`, `FLAC`, `M4A`, `OGG`) через `MediaStore` и мгновенно стартует с локальных треков.
* **Опциональная Яндекс Музыка (кэш + prefetch)**: при указании OAuth-токена в настройках (шестерёнка во вкладке «Ядро») подтягивает «Мою волну» и ищет отсутствующие локально треки, заранее кэшируя **5 треков вперёд** в локальное хранилище. Если трек уже есть на телефоне — играет локальный файл.
* **Бесшовный оффлайн-фолбэк**: при потере сети или недоступности API Яндекс уходит на паузу (circuit breaker), и плеер без сбоев продолжает играть локальную библиотеку.
